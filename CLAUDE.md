# CLAUDE.md for synthcheck

This repository is an R package for the **synthetic authenticity benchmark**. It tests whether
synthetic respondents generated by language models resemble real survey respondents, using three
anchored indices (Overlap, Structure, Behaviour) and a single benchmark score. The design,
the decisions made so far and the work plan are in `PROJECT_BRIEF.md`. Read it before starting
any work.

## Rules

- **Owner's decisions are fixed** unless Okan changes them: The target is all real respondents
  (`clean_real = TRUE` is the alternative). Three anchored columns, with the weakest as the default
  score, which users can change. Exactly eight behaviour features. Response time and text features
  are out of scope.
- **Standalone package.** Do not depend on mirtverse. Code ported from mirtverse keeps its GPL-3
  license and credits mirtverse in the file header and in NEWS.
- **Simple, readable plots.** One picture that reads at a glance. Use the coverage strip palette
  `c("#c0302b", "#f0a09a", "#f0efec", "#86b6ef", "#1c5cab")`: red means fewer or lower than real,
  blue means more or higher, pale means a match.
- **Prose style:** Capitalize the first word after a colon in all prose (README, help pages,
  articles, NEWS). Skip code, function names, URLs, times, ratios and YAML.
- **Checks before a PR:** `devtools::document()`, `devtools::test()` and `R CMD check --as-cran`
  with no errors or warnings. Keep slow fits (person-fit models on all 240 HEXACO items) in
  `\donttest{}` or behind `skip_on_cran()`.
- **Data:** HEXACO answers are raw 1 to 7. Reverse-keyed items (`hexaco_items$reverse`) are keyed
  with `8 - x`. Missing values are `NA`.
- Do not call the package experimental (Okan, 2026-11-13). The caveat must stay clear in the README
  and the help pages: The benchmark compares models and supports decisions about them. It does not
  show that synthetic data can replace a field test.

# synthcheck

**Experimental.** synthcheck checks how authentic synthetic survey
respondents are: Whether respondents generated by large language models
resemble the real people they are meant to stand in for.

It looks at three things:

- **Overlap:** Do synthetic respondents land where real people land?
- **Structure:** Do the items relate to each other as they do in real
  people?
- **Behaviour:** Do synthetic respondents answer the way people do,
  including variability, extreme and midpoint answers, acquiescence,
  consistency and person fit?

Each index is anchored between a shuffled baseline (0) and a second
sample of real people (100). The **synthetic authenticity benchmark**
compares several models in one table, scored by their weakest column by
default.

Three diagnostics sit beside the benchmark and do not change its score:
[`synthetic_construct()`](https://www.okanbulut.com/synthcheck/reference/synthetic_construct.md)
checks whether the scales hold together and relate as they do in real
people (trait correlations, alpha and Tucker’s congruence against a
permutation null),
[`respondent_coverage()`](https://www.okanbulut.com/synthcheck/reference/respondent_coverage.md)
checks whether every real person has a synthetic look-alike, and
`authenticity_benchmark(copula = TRUE)` adds a Gaussian copula row, a
generator without a language model, as a reference.

**No real data yet?**
[`synthetic_pretest()`](https://www.okanbulut.com/synthcheck/reference/synthetic_pretest.md)
screens a new scale on synthetic respondents alone: Item-rest
correlations, items that barely vary or duplicate each other, reverse
keys, reliability, parallel analysis, IRT slopes, and whether the scales
you designed come back. It flags items in each model, temperature,
prompt wording or persona set and shows how many agree. This is pilot
screening, not validation: Language models answer more tidily than
people, so the pretest points to items to read again, and a field test
still decides.

The package compares models and supports decisions about them. It does
not show that synthetic respondents can replace a field test.

## Example

``` r

library(synthcheck)

# Honesty-Humility, Canada: real people and six language models
h <- hexaco_items$item[hexaco_items$trait == "H"]
rev_items <- intersect(h, hexaco_items$item[hexaco_items$reverse])
keyed <- function(d) { d <- d[h]; d[rev_items] <- 8 - d[rev_items]; d }

real <- keyed(hexaco_real[hexaco_real$country == "Canada", ])
ca <- hexaco_llm[hexaco_llm$country == "Canada" & hexaco_llm$attempt <= 4, ]
synthetic <- lapply(split(ca, ca$model, drop = TRUE),
                    function(m) lapply(split(m, m$attempt), keyed))

cov <- synthetic_coverage(synthetic, real, cor = "pearson")
cov
gg_coverage(cov)
```

The synthetic authenticity benchmark takes the raw answers and the item
table, and does the keying itself:

``` r

real <- hexaco_real[hexaco_real$country == "Canada", ]
ca <- hexaco_llm[hexaco_llm$country == "Canada", ]
synthetic <- lapply(split(ca, ca$model), function(m) split(m, m$attempt))

bm <- authenticity_benchmark(synthetic, real, hexaco_items)
bm
gg_benchmark(bm)

# the eight behaviour features behind the Behaviour column
gg_behaviour(bm$behaviour)

# with a Gaussian copula row as a reference
bm <- authenticity_benchmark(synthetic, real, hexaco_items, copula = TRUE)

# diagnostics
gg_construct(synthetic_construct(synthetic, real, hexaco_items))
gg_respondent_coverage(respondent_coverage(synthetic, real, hexaco_items))
```

## Generating synthetic data in an app

[`run_synthcheck_app()`](https://www.okanbulut.com/synthcheck/reference/run_synthcheck_app.md)
opens an app that starts on an About tab with a guided tour and one
question: Do you already have real responses? With real data, the app
benchmarks the models; without it, the app pretests the scale on
synthetic respondents. Then it does the whole workflow: Define an
instrument and personas, generate synthetic respondents with Anthropic,
OpenAI or local Ollama models (with their temperature and the number of
attempts), watch a progress bar with the time left, save the data as
CSV, JSON, RDS or Excel, and benchmark the models against real data with
a plain-language summary for each one.

``` r

install.packages(c("shiny", "bslib", "ellmer", "callr", "jsonlite"))
res <- run_synthcheck_app(real = my_real_data)
res$benchmark
```

API keys typed into the app stay in memory for that session only. Keys
set as `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` in `.Renviron` are used
without being shown. The same steps work in code:

``` r

ins <- sc_instrument(hexaco_items[hexaco_items$trait == "H", ], scale = c(1, 7))
per <- sc_persona_grid(age = c(25, 45, 65), country = c("Canada", "the United States"),
                       template = "You are a {age}-year-old adult living in {country}.")
syn <- generate_synthetic(ins, list(sc_model("anthropic"), sc_model("openai")), per,
                          attempts = 5, respondents = 10, parallel = 8, output = "my_run")

real <- hexaco_real[hexaco_real$country == "Canada", ]
bm <- authenticity_benchmark(as_synthetic_list(syn), real, ins$items)
summarise_benchmark(bm)
```

See the [website](https://www.okanbulut.com/synthcheck/) for a Get
started article, tutorials on each step and a tour of the app with
demos.

## Data

`hexaco_real` holds 17,874 real respondents to the 240 IPIP-HEXACO items
from Canada, Great Britain and the United States (Open-Source
Psychometrics Project). `hexaco_llm` holds 89,597 synthetic respondents
from six language models (10 attempts per country), and `hexaco_items`
holds the item text, facets and keys.
